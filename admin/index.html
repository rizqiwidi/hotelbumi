📡 Tulis Kartu NFC Fisik (Web NFC API)

Program URL tamu langsung ke kartu NFC NTAG213/215/216 dari browser Chrome Android

📋 Panduan Alternatif: Tulis Manual via NFC Tools (iOS / Android / Mac)

  1. Pilih staf atau meja di atas, lalu klik Salin URL.
  2. Buka aplikasi NFC Tools di ponsel Anda.
  3. Pilih tab Write → Add a record → URL / URI.
  4. Tempelkan (Paste) URL yang sudah disalin ke kolom URL.
  5. Tekan Write lalu tempelkan kartu fisik ke bagian sensor NFC ponsel.
  6. Kembali ke halaman ini dan klik tombol Tandai Sudah Diprogram.

Pilih sumber untuk menampilkan QR Code.
