Programmer Kartu NFC Fisik & Kartu QR Tunggal

Program URL atribusi ke chip NFC NTAG213/215/216 melalui Web NFC (Chrome Android) atau cetak kartu individual

Panduan Alternatif: Pemrograman Manual via Aplikasi NFC Tools (iOS / Android)

  1. Pilih staf atau titik meja di atas, lalu klik Salin URL.
  2. Buka aplikasi NFC Tools di ponsel Anda.
  3. Pilih menu Write → Add a record → URL / URI.
  4. Tempelkan URL yang telah disalin, tekan Write, lalu tempelkan kartu NFC ke ponsel.
  5. Klik tombol Tandai Sudah Diprogram di halaman ini untuk memperbarui status kartu.
