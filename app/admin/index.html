📡 Tulis Kartu NFC (Web NFC API)

📋 Panduan: Tulis Manual via NFC Tools (iOS / Laptop)

  1. Pilih staf / meja di atas, lalu klik Salin URL.
  2. Buka aplikasi NFC Tools (tersedia di App Store & Play Store).
  3. Pilih menu Write → Add a record → URL.
  4. Paste URL yang sudah disalin ke kolom URL di NFC Tools.
  5. Tempelkan kartu fisik ke belakang ponsel → tekan Write.
  6. Setelah berhasil, kembali ke portal admin dan klik Tandai Sudah Diprogram.

Pilih sumber untuk menampilkan QR.
